## 为什么是这条线，而不是模型能力

公开讨论几乎全部集中在「模型什么时候能超过人类分析师」。这是个错误的问题。金融业从来不缺聪明的判断，缺的是**敢把判断变成动作的授权**。

英国监管调查显示 75% 的金融机构已使用 AI，但基础模型只占全部用例约 17%，且受监管程度最高的环节在渗透排序上系统性靠后（约 9/21 位）。普及是真实的，进入核心决策没有发生。

这条线值得跟踪，因为它：

- **可验证** —— 招标文件、合同条款与事故披露会把它写出来；
- **决定收入结构** —— 能动钱的系统按结果计价，不能动钱的按席位计价，两者相差一个数量级；
- **非线性** —— 解锁一级需要治理、责任与保险同时到位，因此长期停滞、然后台阶式跳跃。

## 核心框架

**自动化深度 L0—L4** —— 划分依据不是模型能力，而是三个可观察的事实：能否自主产出结论、能否自主执行、后果由谁承担。

| 等级 | 形态 | 可托付金额 |
| --- | --- | --- |
| L0 观察 | 只读与整理，不产出业务结论 | 0 |
| L1 建议 | 逐条人工采纳 | 0 |
| L2 受限执行 | 额度与白名单内自动执行，事后抽检 | **首次离开零** |
| L3 有条件自治 | 默认自动，异常转人工，机构配置准备金 | 场景级上限 |
| L4 全自治 | 无预设额度边界，跨机构自主协商 | 无预设边界 |

**四种控制权** —— 数据权（持续结果标签）、入口权（系统记录位置）、执行权（不经第三方发起真实动作）、责任权（可举证并承担损失）。

## 六个赌注（可证伪）

1. 治理栈会先于模型能力成为采购门槛 · 2026—2028
2. 可托付金额会在若干场景明确离开零 · 2026—2029
3. 强制事故披露会先于保险产品出现 · 2027—2031
4. 代理支付将长期多标准并存 · 2027—2035
5. 价值向执行层、事实层与治理层三分 · 2028—2035
6. 全面自主金融不会在 2035 年前成为主流 · 2030—2035

每条在书中都附有明确的证伪条件。**如果证伪条件先出现，正确的做法是推翻它，而不是解释它。**

## 方法与边界

先用监管文件、审计年报与国际组织报告确定「已经发生了什么」，再在事实上做条件推演，并为每条推演给出可观察的触发与证伪条件。

证据折价规则：公司自报的效率提升只用于判断方向；未经审计的收入与用户数不进入结构性结论；媒体估值与融资传闻完全不采用；产品发布数量不计入商业证明；「覆盖机构数」不等同于付费渗透率。

书末列出三个已知盲区：几乎未讨论保险业、假设了渐进的地缘环境、以机构视角为主。

**本书不构成投资建议。所有公司事实均来自公开披露，不含未公开信息。**
